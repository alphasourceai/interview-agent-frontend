# alphaScreen brand masters

Source artwork: `alphaScreen-logo-directions.pdf`, supplied by the owner.

- `08` is the canonical static mark.
- `09` is a motion-only transition state and must not appear by itself.
- `duotone` is the primary digital treatment.
- `gradient`, `navy`, and `white` are approved contextual variants.
- Documents and legal surfaces use a static `08` treatment.
- Listening or processing surfaces may transition `08` → `09` → `08` for no more than three cycles.
- Reduced-motion environments remain on static `08`.

The SVG masters in `marks/` contain vector paths only. They were traced from the exact source-PDF images and verified by rendering them back to the 1100 × 1100 source dimensions for comparison.
